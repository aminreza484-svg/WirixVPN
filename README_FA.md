# Wirix VPN – Android UI Prototype

این مخزن نسخه اولیه رابط کاربری اندروید Wirix VPN است.

## وضعیت فعلی
- پیاده‌سازی با Kotlin و Jetpack Compose
- صفحات خانه، فعال‌سازی کد، سرورها و حساب کاربری
- ناوبری پایین صفحه
- انتخاب سرور و تغییر وضعیت اتصال صرفاً در سطح رابط کاربری
- فیلد ورود کد ۱۶ رقمی با اعتبارسنجی طول ورودی

## مواردی که عمداً هنوز پیاده‌سازی نشده‌اند
- اتصال واقعی WireGuard یا هر پروتکل VPN
- API، احراز هویت و دیتابیس مرکزی
- اعتبارسنجی واقعی کد خرید و افزودن حجم
- آمار واقعی مصرف و پینگ
- تاریخچه خرید و مصرف از سرور

مقادیر نمایشی در رابط کاربری با عنوان نمونه/آزمایشی مشخص شده‌اند و نباید به‌عنوان داده واقعی استفاده شوند.

## پیش‌نیازها
- Android Studio جدید
- JDK 17
- Android SDK 35

## اجرا
1. پوشه پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync کامل شود.
3. یک دستگاه یا شبیه‌ساز با Android 8.0 (API 26) یا بالاتر انتخاب کنید.
4. Run را بزنید.

برای ساخت APK آزمایشی:
`./gradlew assembleDebug`

خروجی در مسیر زیر قرار می‌گیرد:
`app/build/outputs/apk/debug/app-debug.apk`

## ساختار
- `app/src/main/java/com/wirix/vpn/MainActivity.kt` رابط کاربری و صفحات
- `app/src/main/AndroidManifest.xml` تنظیمات پایه برنامه
- `app/build.gradle.kts` وابستگی‌ها و تنظیمات ماژول

## گام‌های توسعه بعدی
1. تعریف قرارداد API بین ربات و اپلیکیشن
2. پیاده‌سازی ورود/اتصال حساب
3. اتصال صفحه فعال‌سازی به API
4. دریافت فهرست سرورها از بک‌اند
5. افزودن تونل واقعی با WireGuard Android و مدیریت مجوز VPN اندروید
6. دریافت آمار مصرف معتبر از زیرساخت سرور


## ساخت APK مستقیماً در GitHub Actions

1. فایل ZIP پروژه را استخراج کن و کل محتویات پوشه را داخل یک Repository در GitHub آپلود کن.
2. مطمئن شو فایل `.github/workflows/android.yml` هم همراه پروژه آپلود شده باشد.
3. وارد تب **Actions** مخزن شو.
4. از فهرست سمت چپ، **Build WirixVPN APK** را انتخاب کن و روی **Run workflow** بزن.
5. بعد از پایان موفقیت‌آمیز اجرا، وارد همان اجرای Workflow شو؛ در بخش **Artifacts** فایل `WirixVPN-debug-APK` را دانلود کن.
6. فایل ZIP دانلودشده را باز کن؛ فایل APK داخل آن است.

با هر Push به شاخه `main` یا `master` نیز Workflow به‌صورت خودکار اجرا می‌شود. این خروجی نسخه Debug و آزمایشی است، نه APK انتشار نهایی امضاشده. برای این نمونه، اتصال واقعی VPN و سرور هنوز پیاده‌سازی نشده است.
